c#制作的背单词软件，可以实现背单词，单词听写，英语短文阅读的功能
=======
与他人合作完成的c#桌面端英语学习软件，集成词典查询、单词背诵、词库管理、阅读辅助和智能练习五大核心功能。系统采用MySQL数据库存储词库数据，通过模块化设计实现高效学习管理，主要特点包括：智能词典：支持通配符模糊搜索，实时显示音标、例句及释义。多模式学习：提供中英互译背诵、拼写测试、选择题/填空题自动生成。个性化词库：内置四六级/考研等标准化词库，支持CSV格式自定义导入（自动去重校验）。阅读辅助：内置文章阅读器，双击生词即时查询单词释义及音标等信息。数据可视化：练习结果统计、错题自动归类、学习进度跟踪。多元背诵模式：包含中译英、英译中、听写测试，可选多种词库进行学习，包含用户导入的词库。收藏夹功能：学习单词时可将单词加入收藏夹，便于查看对于用户来说重要的单词列表。
